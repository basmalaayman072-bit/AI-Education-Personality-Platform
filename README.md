# AI Education Personality Platform  
**منصة الذكاء الاصطناعي للتعلم المخصص حسب الشخصية**

> مشروع بحثي في مجال **AI in Education**  
> إعداد: **بسملة أيمن** – كلية التربية – جامعة بنها  
> تخصص: تدريس العلوم باللغة الإنجليزية (المرحلة الابتدائية)

---

## فكرة المشروع

منصة ذكية تهدف إلى بناء **ملف تعليمي متعدد الأبعاد للمتعلم** اعتماداً على مجموعة من بياناته وخصائصه، ثم استخدام هذا الملف لتقديم تجربة تعلم أكثر تخصيصاً وملاءمة لاحتياجات كل طالب.

تعمل المنصة على:

1. **بناء الملف الشخصي التعليمي** من خلال بيانات المتعلم وتفضيلاته.
2. **تخصيص المحتوى التعليمي** بما يتناسب مع خصائص المتعلم وطريقة تفاعله مع المادة.
3. **توليد تقييمات ذكية** تساعد على قياس الفهم والتطبيق وتقديم تجربة تقييم أكثر ملاءمة للطالب.
4. **تخزين الملف محلياً** وإتاحة تحديثه مع تطور بيانات المتعلم.

## المميزات الحالية (النسخة الأولية)

- واجهة عربية حديثة ومتجاوبة
- بناء ملف تعليمي متعدد الأبعاد
- تحليل أولي لخصائص المتعلم وتفضيلاته
- حفظ الملف الشخصي محلياً
- تكييف المحتوى التعليمي وفق الملف الشخصي
- توليد أسئلة تقييم مخصصة
- تصميم قابل للتطوير إلى نظام ذكاء اصطناعي متكامل

> **ملاحظة بحثية:** النسخة الحالية نموذج أولي (Prototype) لإثبات الفكرة، وبعض مكونات التحليل تجريبية ولا تُستخدم للتشخيص النفسي أو لاتخاذ قرارات تعليمية عالية المخاطر.

## التقنيات المستخدمة

- HTML5 + CSS3 + JavaScript (Vanilla)
- LocalStorage لحفظ البيانات
- تصميم متجاوب (Responsive)
- جاهز للرفع على GitHub Pages
