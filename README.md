# AI Education Personality Platform  
**منصة الذكاء الاصطناعي للتعلم المخصص حسب الشخصية**

> مشروع بحثي في مجال **AI in Education**  
> إعداد: **بسملة أيمن** – كلية التربية – جامعة بنها  
> تخصص: تدريس العلوم باللغة الإنجليزية (المرحلة الابتدائية)

---

## فكرة المشروع

منصة ذكية تحلل شخصية المتعلم باستخدام علوم متعددة (علم الأعداد – الأبراج – أبجد – أنماط التعلم)، ثم تقوم بـ:

1. **تحليل الشخصية** من خلال:
   - الاسم الكامل
   - تاريخ الميلاد
   - صورة الوجه (للتحديث السنوي)
2. **تكييف المحتوى التعليمي** حسب شخصية المتعلم وطريقة تعلمه (بصري / سمعي / حركي...).
3. **توليد تقييمات ذكية** تناسب أسلوب تعلم الطالب وتنمي فهمه الحقيقي للدروس.

## المميزات الحالية (النسخة الأولية)

- واجهة عربية حديثة وجميلة
- تحليل فوري للشخصية (Numerology + Astrology + Abjad + Learning Style)
- حفظ ملف الشخصية محلياً مع إمكانية التحديث السنوي
- رفع محتوى (نص / ملف) وتحويله حسب نمط التعلم
- توليد أسئلة تقييم مخصصة
- تصميم احترافي جاهز للتطوير والبحث

## التقنيات المستخدمة

- HTML5 + CSS3 + JavaScript (Vanilla)
- LocalStorage لحفظ البيانات
- تصميم متجاوب (Responsive)
- جاهز للرفع على GitHub Pages

- تحليل ملامح الوجه باستخدام Computer Vision
- نظام حسابات مستخدمين سحابي
- دعم رفع ملفات PDF و Word و روابط يوتيوب بشكل كامل
